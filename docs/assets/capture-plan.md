# Documentation capture plan

- **Purpose:** capture the real Argoscope portfolio dashboard for README documentation.
- **Source:** local app route http://127.0.0.1:<port>/ using synthetic repository observations.
- **Command/settings:** shot-scraper http://127.0.0.1:5174/portfolios/<id>/overview?window=30d --output docs/assets/README.jpg --width 1440 --height 900 --wait 3000 --quality 85. App started with ASPNETCORE_ENVIRONMENT=Screenshot so the in-memory `Seed` config seeds four synthetic repositories (example/demo-app, example/ingest-pipeline, competitor-a/rival-monitor, competitor-b/scout-board), four owner-managed package associations (DockerHub, npm, PyPI, crates.io) and runs an initial collection pass for both GitHub metrics and package adoption.
- **Artifact:** docs/assets/README.jpg (regenerated 2026-09-30; 1440×900 JPEG, quality 85). A second artifact docs/assets/adoption.jpg (regenerated 2026-09-30; 1440×900 JPEG, quality 85) shows the per-repository package adoption page. A third artifact docs/assets/decisions.jpg (regenerated 2026-09-30; 1440×900 JPEG, quality 85) shows the portfolio-level decision journal page (record form + journal list with revisions, edit, delete, and history actions). All three use only synthetic data and the local app.
- **Revision/time:** capture taken against bootstrap revision that implemented github-portfolio-momentum-mvp; re-captured on the package-adoption-metrics revision (no live GitHub or registry calls; the fake provider plus the in-memory `Seed` config populate the data). Re-captured again on the portfolio-decision-journal revision to add docs/assets/decisions.jpg; the decision form is exercised with the same in-memory seed and the journal list shows a synthetic decision with two `Unresolved` evidence references (the live app is offline, so the smoke run used the same seed and a curl POST to /api/v1/portfolios/<id>/decisions). Capture timestamp 2026-09-30T11:25Z.
- **Privacy review:** PASSED. The capture uses only synthetic repository names, synthetic package coordinates and synthetic metric data declared in src/Argoscope.Api/appsettings.Screenshot.json. No live GitHub call is performed: the fake GitHub provider is used, no token is configured, and the daily hosted service is disabled. No live package-registry call is performed: the stub HTTP adapters are replaced with in-memory `FakePackageMetricsProvider` instances per provider; the only HTTP requests originate from local synthetic data load. No real owner logins, real repository identities, real package coordinates, real metric values, or traffic details appear in the screenshot. The as-of timestamp in the UI is server time and does not reveal any real data. The decisions page does not render any package coordinates, repository names, or metric values from production — only the synthetic rationale, type, and date from the smoke test POST against the in-memory database. Evidence references on the rendered journal row carry `Unresolved` markers because the smoke references point at non-existent snapshot / package-observation ids in the in-memory store; no real id is leaked.
- **Status:** DONE. The active OpenSpec change produced a runnable application; the screenshots above are the genuine rendered dashboard, adoption, and decision-journal views. Future changes to the UI must regenerate this artifact and re-record the timestamp and privacy review.
